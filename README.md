# ФотоМоменты

Учебный адаптивный лендинг фотопечати с калькулятором стоимости и интеграцией Яндекс Формы.

## Описание
Лендинг с расчётом стоимости печати фотографий с учётом формата, бумаги, количества, срочности и встроенной формой оформления заказа.

## Возможности
- Адаптивный интерфейс
- Калькулятор стоимости (скидка 10% от 50 фото, надбавка 30% за срочность)
- Интеграция Яндекс Форм (iframe, предзаполнение итоговой суммы)
- Служебные страницы: /privacy, /offer, /order-complete
- SPA-маршрутизация (React Router)
- Готово к деплою на Netlify

## Технологии
- React + TypeScript + Vite
- React Router DOM
- Чистый CSS
